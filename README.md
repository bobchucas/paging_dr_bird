# Custom Emoji Leaderboard

A single-page dashboard tracking who's creating the most custom emoji in your Slack workspace — with a special focus on how close Scott Bird is to owning 50% of them.

## Features

- **Progress ring** — Scott's current % of all emoji, animated, with a 50% goal marker
- **Progress bar** — how many more emoji he needs to hit 50%
- **Closest competitors** — the 3 people nearest his count (above or below)
- **Most active days** — bar chart of which days of the week he uploads most
- **Weekly leaderboard** — who added the most emoji this calendar week
- **All-time leaderboard** — full ranked table of every creator

## Setup

### 1. Slack token (one-time)

You need a **user token** (starts with `xoxp-`) with the `admin.emoji:read` scope.
A bot token won't work — this API requires a real user who is a workspace admin.

1. Go to [api.slack.com/apps](https://api.slack.com/apps) and open your app
2. Click **OAuth & Permissions** in the sidebar
3. Scroll to **User Token Scopes** and add `admin.emoji:read`
4. Click **Reinstall to Workspace** at the top of the page
5. Copy the **User OAuth Token** (starts with `xoxp-`)

> If you don't see the `admin.emoji:read` scope option, your workspace may need a paid Slack plan (Pro or above).

### 2. Fetch the data locally

```bash
pip install requests
SLACK_TOKEN=xoxp-your-token python fetch_emoji.py
```

This creates `data/emoji.json`. Check the output — it will tell you the top creator and total counts.

### 3. Preview locally

Opening `index.html` directly in your browser **won't work** due to browser CORS restrictions on `file://` URLs. Instead, run a local server:

```bash
python -m http.server 8080
# then open http://localhost:8080
```

## Hosting (free) — GitHub Pages

1. Create a new **public** GitHub repository
2. Push this entire directory to it:
   ```bash
   git init
   git add .
   git commit -m "initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
3. In the repo on GitHub, go to **Settings → Pages**
4. Under "Source", select **Deploy from a branch**, choose `main`, folder `/root`
5. Save — GitHub will give you a URL like `https://your-username.github.io/your-repo/`

That's it. The dashboard is now live and public.

### Auto-refresh with GitHub Actions

To keep the data fresh automatically (e.g. every Monday):

1. In your GitHub repo, go to **Settings → Secrets and variables → Actions**
2. Click **New repository secret**, name it `SLACK_TOKEN`, paste your `xoxp-` token
3. The workflow in `.github/workflows/refresh.yml` is already configured — it will run every Monday at 9am UTC and commit updated data

You can also trigger it manually from the **Actions** tab at any time.

## Customisation

At the top of `index.html` there's a `CONFIG` block:

```js
const CONFIG = {
  targetName:       "Scott Bird",   // Slack display name (partial match OK)
  targetUserId:     null,           // Set to Slack user ID for exact matching
  weekStartsMonday: true,           // true = Mon–Sun week, false = Sun–Sat
  dataFile:         "data/emoji.json",
};
```

If Scott's display name in Slack is different (e.g. "Scott B"), update `targetName` to match.
For rock-solid matching, set `targetUserId` to his Slack user ID (visible in his profile URL or in the JSON output after fetching).
